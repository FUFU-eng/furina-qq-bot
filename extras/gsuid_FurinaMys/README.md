# FurinaMys · 芙宁娜米游社助手

把四个官方游戏插件（GenshinUID / StarRailUID / ZZZeroUID / BBBUID）的常用功能收拢成几条 **@机器人** 指令：

| 指令（都要先 @芙芙） | 说明 |
| --- | --- |
| 绑定账号 | 群里发米哈游通行证二维码，扫码后自动撤回，并一次绑定通行证下全部游戏账号、开启每日自动签到 |
| 我的账号 | 查看已绑定的全部游戏账号卡片 |
| ys每日 / bt每日 / zzz每日 / bbb每日 | 实时便笺（体力、委托、派遣……） |
| ys芙宁娜 / bt黄泉 / zzz星见雅 / bbb任意女武神 | 角色面板（崩坏3 为女武神总览） |
| ys芙宁娜攻略 …… | 一图流攻略（崩坏3 为往世乐土攻略） |
| ys深渊 / bt深渊 / zzz深渊 / bbb深渊 | 一次发全套终局战绩图 |
| ys今日素材 | 今日材料（仅原神） |
| 更新展柜 / ys更新展柜 | 刷新全部（或单个）游戏的角色面板数据 |
| 指令帮助 | 精美指令卡片 |

查询、绘图全部调用上游插件原函数；本插件只负责路由、绑定流程和三张卡片（二维码 / 账号 / 帮助）。
