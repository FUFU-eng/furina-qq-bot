# FurinaSign

芙宁娜米游社签到战报（本项目自带的 GsCore 插件，不修改任何上游插件）。

- 签到本身仍由 GenshinUID / StarRailUID / ZZZeroUID / BBBUID 的官方定时任务执行；
- 本插件只在签到完成后**只读查询**各账号今日签到状态，并在群里发送「问候 + 签到总结卡片」；
- 卡片用 GsCore 自带的 Takumi HTML 渲染（MiSans + Twemoji，不会出现豆腐块）。

## 指令（前缀「米游社」）

| 指令 | 说明 |
|---|---|
| `米游社签到` | 立即为自己已绑定的四个游戏执行签到（调用上游签到函数），回复个人签到卡片 |
| `米游社签到总结` / `米游社战报` | 群管理员：查看本群今日签到总结 |
| `米游社战报推送` | 超级用户：立即向所有目标群推送今日战报 |

## 配置（GsCore 控制台 → 插件配置 → FurinaSign）

- `ReportEnable`：是否发送群战报
- `ReportTime`：发送时间（默认比上游签到时间晚 15 分钟），修改后热生效
- `ReportGroups`：指定推送群；留空则使用芙宁娜面板「功能权限 → 米游社签到」开启的群
